# Élan Fitness
```
Élan Fitness — Ton énergie, ton rythme.
```
Élan Fitness est un projet de site web présentant une salle de sport moderne à Casablanca, au Maroc. Le site propose des informations sur la salle, ses programmes sportifs, ses valeurs et ses coordonnées.
## Aperçu du projet
L’objectif de ce projet est de créer un site web simple et attrayant pour présenter la salle de sport et ses services.
## Website Pages
### 1. Accueil :
```
Présentation d’Élan Fitness et de ses services : coaching, équipements et activités sportives.
```
### 2. À propos :
```
Découvrez notre mission, nos valeurs et notre engagement pour votre bien-être.
```
### 3. Programmes :
```
Découvrez nos activités sportives :
  -Musculation
  -Yoga
  -Cardio
  -Boxe fitness
```
### 4. Contactez-nous :
```
Retrouvez nos coordonnées pour nous contacter facilement.
```
## Technologies Utilisés
- HTML5 — Structure et contenu du site web.
- CSS3 — Mise en page, style et présentation visuelle.
- Google Fonts — Typography.
